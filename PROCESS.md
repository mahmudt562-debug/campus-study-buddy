# Campus Study Buddy - Development Process

## Process Model
Scrum

Campus Study Buddy will use Scrum because the project can be developed in small parts and improved as development continues. Since I am working on this project individually, Scrum will help me organize the work into manageable tasks and keep track of my progress.

## Sprint 1
**Length:** 2 weeks

**Goal:** Create the basic structure and core features of Campus Study Buddy so students can organize their courses and academic tasks.

### Sprint 1 Items
- Design the main student dashboard
- Create course management feature
- Create assignment and task feature
- Add due dates for assignments and exams
- Create task completion feature
